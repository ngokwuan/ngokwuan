### ⚙️ [FlowForge](https://github.com/ngokwuan/flowforge)

*A visual workflow automation platform with an AI-assisted builder.*

<img src="https://img.shields.io/badge/status-in%20development-orange?style=flat-square" alt="status" />
<img src="https://img.shields.io/badge/NestJS-E0234E?style=flat-square&logo=nestjs&logoColor=white" alt="nestjs" />
<img src="https://img.shields.io/badge/Next.js-000000?style=flat-square&logo=nextdotjs&logoColor=white" alt="nextjs" />
<img src="https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white" alt="postgres" />
<img src="https://img.shields.io/badge/Redis%20%2B%20BullMQ-DC382D?style=flat-square&logo=redis&logoColor=white" alt="redis" />

</div>

Design workflows on a drag-and-drop canvas, trigger them from webhooks or schedules, and watch every execution run step by step in real time.

- 🧩 DAG execution engine with parallel branches, retries with exponential backoff and a dead-letter queue
- 🔁 Idempotent webhooks and cron triggers that fire exactly once across multiple instances
- 🔐 Multi-tenant workspaces with RBAC, JWT refresh rotation, OAuth2 and AES-256-GCM encrypted credentials
- 📡 Real-time execution view over WebSocket (Socket.IO)
- 🤖 AI text-to-workflow with structured, validated output
